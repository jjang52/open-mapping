# Open Critical Mapping Workshop

The Open Critical Mapping Workshop builds capacity for open spatial-data analysis for Morehouse College faculty and students. Leveraging **R** and the **U.S. Census Bureau API (`tidycensus`)**, participants examine longitudinal demographic shifts and neighborhood change across Atlanta and Georgia while developing reproducible, public-facing analytical workflows.

---

## 🧭 Workshop Overview

Through hands-on computational labs, participants query multi-year American Community Survey (ACS) datasets, process spatial features using `sf`, and visualize socioeconomic variables across local and statewide scales.

### Deliverables
Each participant completes an end-to-end, reproducible spatial analysis pipeline, delivering:
* **Reproducible Analytical Notebooks (`.Rmd` & compiled `.pdf`):** A fully documented research notebook pairing methodological narratives with executable code and rendered outputs.
* **Production R Scripts (`.R`):** A standalone, top-to-bottom pipeline automating API data extraction, spatial transformations, and plotting.
* **Multi-Scale Longitudinal Map Series:** High-resolution tract-level visualizations analyzing shifts across Fulton County and statewide Georgia across two distinct Census vintages (2017 vs. 2024).

---

## 💡 Takeaways

Beyond foundational spatial literacy, participants exit the workshop with concrete professional assets:

* **Real-World Open Source Tooling:** Practical experience building reproducible research pipelines with industry-standard open-source ecosystems (`R`, `tidyverse`, `sf`, `ggplot2`).
* **Data Science Pathway Exploration:** Immersion into computational social science, policy analysis, and spatial econometrics as viable research and career trajectories.
* **Portfolio-Ready Deliverables:** A public-facing, publication-grade spatial portfolio demonstrating data wrangling, API integration, and critical geographic inquiry.
